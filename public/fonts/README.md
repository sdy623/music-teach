# Optional User-Licensed Score Font

Place a licensed score font here using one of these names:

- `jpw-score.woff2`
- `jpw-score.ttf`
- `jpw-score.otf`

The app will load it as `JPWScoreUser` and use it before fallback fonts.

For vector extraction, use an OTF or TTF source with `npm run glyphs:extract` or `node scripts/extract-score-glyphs.mjs --digit-font path/to/font.otf`.
