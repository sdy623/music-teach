# 简谱记号渲染规范层

本文记录教学 Slide 主渲染路径的记谱依据和不可回退规则。UI 可以替换，以下几何与语义约束不能由页面样式覆盖。

## 对照材料

- 简谱出版规范：核对减时线、增时线、小节线、拍号与反复记号。
- JP-Word 导出样张：核对调号、速度音符、休止符和歌词锚点。
- 人工复核过的五线谱：只验证旋律与节奏语义，不复制其版面。

这些 PDF 是离线校准证据。运行时只消费 `ScoreIR` 和 `JianpuPhraseFrame`，不会切割 PDF 页面。

## 减时线

1. 第一层减时线位于数字下方；第二、第三层按固定垂直间距继续向下。
2. 第一层只在一个单位拍内部连接，绝不跨拍或跨小节。
3. 第二层及更深层按二分层级继续拆组。例如一个拍内连续八个三十二分音符的线段数为 `1 / 2 / 4`。
4. `3/8` 作为一个三八分音符组；`6/8` 为 `3+3`；`9/8` 为 `3+3+3`。
5. 规范样例中的不规则分组保留为显式规则：`5/8 = 2+3`，`5/4 = 3+2`。
6. 低音点必须在最深一层减时线下方，并保留净空。
7. 休止符 `0` 和节奏符 `X` 使用同一时值分组规则；`X` 不生成音高。

实现位于 `src/notation/jianpuRules.ts` 与 `src/slide/layoutPhrase.ts`。

## 增时、附点与八度

- 增时线是与单个数字占位宽度一致的水平矢量线，不使用连字符字体。
- 增时线线宽为数字字号的 10%，使用独立于减时线的粗线宽。
- 附点位于数字右侧中部，多附点按固定水平间距排列。
- 高音点在数字上方；低音点在数字或最深减时线下方。
- 增时占位继续参与拍内时间位置和歌词对齐，但不产生新的歌词发音。

## 标准音乐字形

数字、线和点由 SVG primitive 绘制。需要标准字形轮廓的项目统一使用仓库内带 OFL 许可证的 Bravura SMuFL：

- 升、降、还原记号
- 拍号数字
- 速度标记中的四分音符

字形映射集中在 `src/notation/smufl.ts`。业务组件不得直接散写私用区 code point。

## 小节线与反复

| JPW-ABC | 语义 | 几何 |
| --- | --- | --- |
| `|` | 单小节线 | 单细线 |
| `||` | 双纵线 | 两条等粗细线 |
| `|]` | 终止线 | 左细、右粗 |
| `[|` | 起始线 | 左粗、右细 |
| `|:` | 前反复 | 左粗、右细，圆点在右 |
| `:|` | 后反复 | 左细、右粗，圆点在左 |

纵线只覆盖简谱符号带，不延伸到歌词。

## 连音与三连音

- 普通圆滑线和延音线使用独立曲线语义，不能从括号数量直接画成一条超长弧。
- 三连音遵循 JP-Word：两段渐变粗细的弧线，Bravura SMuFL 数字居于弧顶缺口；弧线避让整组音符、装饰音和圆滑线。
- 二音三连音允许存在，但必须在结构边界内结束，不能吞入下一小节的音符。
- tie ghost 只改变延音后续音的符号透明度，歌词位置和不透明度保持不变。

详细语法、倚音与连续伴奏规则见 [三连音、倚音与伴奏段落](neo/notation-semantics-update.md)。
